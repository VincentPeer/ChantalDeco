# ChantalDeco Showcase Website

This repository contains the source code for the ChantalDeco showcase website.

This website is built with [React](https://react.dev/) and [Next.js](https://nextjs.org/).

## Getting Started

To run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
